# 概要

STM32F103C8T6（Bluepill）をArduino環境で動作させ、**2個のSPI接続アブソリュート磁気エンコーダ**（14bit）で角度を読み取り、**CAN経由で受信した目標角度**に従って**2つのDCモータ**を制御するファームウェアです。CANは**eXoCAN**ライブラリを用いて500kbpsで動作します。

## ハードウェア構成（ピン）

- Bluepill LED: `PC13`  
- エンコーダ CS: `CS1=PB0`, `CS2=PB1`  
- モータ1: 方向 `M1_D=PA15`, 駆動 `M1_P=PB3`  
- モータ2: 方向 `M2_D=PB4`, 駆動 `M2_P=PB5`  
- デバッグ用UART: `Serial2`（TX=PA_2, RX=PA_3, 115200bps）  
- CAN: eXoCAN / PA11-PA12（PORTA_11_12_XCVR）  

## 接続デバイス

- **SPIエンコーダ ×2**  
  - SPI設定: 100 kHz, MSB First, **MODE1**  
  - 16bit転送で読み出し、上位2bit（PAR/EF）をマスクして14bit角度に変換  

- **CANトランシーバ ×1**（500 kbps, 11bit ID）  
  - 受信割り込みでフレームを取得  

- **DCモータドライバ ×2**（方向/駆動の2線制御）  

## CANプロトコル

- **受信ID**: `0x06A`（外部PC→本機）  
- **送信ID**: `0x069`（本機→外部PC）  

### 受信（0x06A）

受信データの**先頭バイト `ch`** により動作が切り替わります：

- `ch = 0`: 現在角度をそのまま目標角度に採用  
  `tgt_1 = pos_1`, `tgt_2 = pos_2`
- `ch = 1`: 目標角度を設定  
  - `tgt_1 = m2 + 255 * m1`  
  - `tgt_2 = m4 + 255 * m3`  
  （※2バイト結合は **255倍** で実装）
- `ch = 9`: 現在角度の送信を要求  

### 送信（0x069）

**現在角度のスナップショット**を応答として送出。フレームは以下8バイト：

[0]=0x00,
[1]=highByte(pos_1), [2]=lowByte(pos_1),
[3]=highByte(pos_2), [4]=lowByte(pos_2),
[5]=0xFF, [6]=0xFF, [7]=0xFF

## 角度計算と平滑化

- エンコーダの14bit値を**移動平均（30サンプル）**で平滑化  
- `deg = raw / 16384.0 * 360.0` で角度に変換  
- 整数化して `pos_1`, `pos_2` を得る  

## モータ制御ロジック

- **デッドゾーン**：モータ1は `±5°`  
- 目標との差がしきい値以上なら回転方向を決定し駆動、未満なら停止  
- 制御は方向線（`*_D`）と駆動線（`*_P`）で実行  

## システム初期化の流れ

1. CAN初期化（500kbps, フィルタ/割り込み設定）  
2. 各GPIO初期化・SPI開始・UART開始（115200bps）  
3. 起動直後に**100回**エンコーダを読み、移動平均バッファをウォームアップ  
4. 初期目標角度 `tgt_1`, `tgt_2` を**現在角度**に合わせる  

## メインループ

- エンコーダ読取り → 移動平均 → 角度計算  
- CAN受信を処理（`ch`に応じて目標更新/送信要求）  
- 目標角度に向けたモータ制御を実行  
- `ch=9`を受けてフラグが立った場合、**現在角度をCAN送信**  

## ビルド/実行メモ

- Arduino Core for STM32（Bluepill）＋ eXoCAN ライブラリを利用  
- ボーレート：CAN 500kbps、UART 115200bps  
- エンコーダは **SPI MODE1 / 100 kHz** で接続  
- CSは `PB0`/`PB1` を個別に制御
