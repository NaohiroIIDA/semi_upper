# CAN プロトコル仕様

| 項目 | 値 |
|---|---|
| ビットレート | 500 kbps |
| ID 形式 | 標準 11bit |
| データ長 | 8 バイト固定 |
| PC → マイコン | **ID `0x06A`** |
| マイコン → PC | **ID `0x069`** |

角度の単位は **度（整数, 0〜359）** で、2バイト（上位, 下位）で表します。

## PC → マイコン（ID `0x06A`）

先頭バイト `cmd` でコマンドを指定します。

| byte | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 内容 | `cmd` | 軸1 上位 | 軸1 下位 | 軸2 上位 | 軸2 下位 | 未使用 | 未使用 | 未使用 |

### `cmd = 0` : 停止（現在位置を保持）

現在の角度を目標角度に設定します。結果としてモータは停止します。byte1〜7 は使いません。

### `cmd = 1` : 目標角度の設定

byte1〜4 の値を軸1・軸2の目標角度として設定します。

```
目標角度1 = byte1 * 255 + byte2
目標角度2 = byte3 * 255 + byte4
```

> ⚠️ ファームウェアは **×255** で結合していますが、Python ツールは通常のビッグエンディアン（×256）で
> エンコードしています。256°以上を指定すると 1° 小さく解釈されます。
> 詳細は [known-issues.md](known-issues.md#1-角度の2バイト結合が255) を参照してください。

例: 軸1=220°, 軸2=90°

```
ID 0x06A : 01 00 DC 00 5A FF FF FF
```

### `cmd = 9` : 現在角度の要求

マイコンが次のループで、ID `0x069` で現在角度を返信します。byte1〜7 は使いません
（`monitor_and_ping.py` は `09 00 00 00 00 FF FF FF` を送ります）。

### その他の `cmd`

無視します（何もしません）。

## マイコン → PC（ID `0x069`）

`cmd = 9` を受け取ったときだけ送信します（定期送信はしません）。

| byte | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 内容 | `0x00` | 軸1 現在角度 上位 | 軸1 下位 | 軸2 現在角度 上位 | 軸2 下位 | `0xFF` | `0xFF` | `0xFF` |

ここで返す角度は **移動平均後の値** で、通常のビッグエンディアン（上位×256 + 下位）です。

例: 軸1=300°, 軸2=45°

```
ID 0x069 : 00 01 2C 00 2D FF FF FF
```

## 受信フィルタについて

ハードウェアの CAN フィルタはすべてのメッセージを通す設定です。ID のチェック（`0x06A` かどうか）は
ファームウェア側で行っています。
